# NCG — Gabinete numismático

NCG es un juego de gabinete numismático para Windows y Linux. Se está preparando para publicar su código y automatizar compilaciones y firmas de Windows.

**Estado del repositorio:** importación de fuentes en curso. Este repositorio aún no contiene todos los recursos necesarios para ejecutar el juego; no uses sus compilaciones parciales como entregas oficiales. Las versiones completas V18.36.15 se mantienen fuera del repositorio hasta revisar la distribución de los recursos multimedia.

## Código y licencia

El código original aportado al repositorio se ofrece bajo los términos de [MIT](LICENSE), únicamente en la medida en que los contribuidores tengan derechos para licenciarlo. No se aplica automáticamente a música, imágenes de referencia ni binarios de terceros. Consulta [LICENSE_SCOPE.md](LICENSE_SCOPE.md).

## SignPath Foundation

La firma Authenticode **aún no está habilitada**: el proyecto debe ser admitido en SignPath Foundation, verificar los derechos de los componentes distribuidos y configurar el flujo de compilación de confianza. La firma requiere aprobación humana. [Condiciones oficiales](https://signpath.org/terms).

## Recursos

La creadora declara que las imágenes numismáticas de NCG son recreaciones generadas con IA. La música incorporada en versiones de juego anteriores está identificada en sus metadatos como **“Loop 4 – [Lofi/Rainy Chillhop] – Guitar, Bass, Drums”, de Foam (2020)**; no se ha localizado todavía la página y licencia individual de esta pista para su publicación en el repositorio.
